## Directory notes

- `papers/` — paper close-reading notes; filenames use `<algo>_<venue_year>.md` (lowercase snake_case)
- `benchmarks.md` — comparison table of multiple algorithms on the same dataset (auto-generated by `scripts/collect_results.py`; do not edit by hand)
- `prompts.md` — maintenance prompt handbook: standard prompt templates for various maintenance tasks; copy when starting a new AI session
