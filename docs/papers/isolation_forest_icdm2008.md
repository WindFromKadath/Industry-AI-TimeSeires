## 动机

传统异常检测多先建模"正常"的分布再识别偏离者,容易把正常点误判为异常。本文换一个角度:异常点"少而不同",在随机划分下更容易被**孤立**,因此直接度量"孤立的难易程度"而非建模分布。

## 方法

- **iTree(隔离树)**:递归地随机选一个特征、在该特征取值范围内随机选切分点,直到样本被单独隔离或达到树高上限。
- **路径长度 h(x)**:样本 x 从根到叶子的切分次数;异常点的期望路径长度 E(h(x)) 显著更短。
- **异常分数(Eq. 1-3)**:s(x, n) = 2^(-E(h(x)) / c(n)),其中 c(n) 为 n 个样本的二叉搜索树平均路径长度(归一化项)。s 接近 1 为异常,接近 0.5 为正常。
- **iForest**:t 棵树集成,每棵树用子采样(默认 ψ=256)训练,天然适合大数据、线性复杂度。

## 实验设置

论文在多个真实数据集上与 ORCA、LOF、RF 等对比,AUC 更优且运行时间显著更低;子采样大小 ψ 取 256 在多数数据集上已收敛。

## 复现要点

- `sklearn.ensemble.IsolationForest` 是该算法的成熟实现,复现重点在于**特征构造与评价口径**(时序上需滑窗特征,指标用 AP/ROC-AUC 而非硬阈值精度)。
- `contamination` 参数对应异常比例先验,影响阈值换算;用决策函数直接打分时对结果影响很小。
- 论文 2008 年发表、无官方代码,复现以 sklearn 实现为准,数值结论不可逐字对齐,关注趋势一致性。
